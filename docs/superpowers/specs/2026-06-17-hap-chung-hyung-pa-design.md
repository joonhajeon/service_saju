# 합·충·형·파 시각화 설계

**날짜:** 2026-06-17  
**범위:** 사주 4기둥(시/일/월/년) 천간+지지 간 관계 표시. 대운/세운은 향후 확장.

---

## 기능 요약

사주표 오른쪽 위에 토글 버튼을 추가한다. 버튼을 누르면 사주표의 해당 글자 셀에 색상 테두리가 표시되고, 표 바로 아래에 관계 요약 배지가 나타난다.

---

## UI

### 버튼
- 위치: 사주표 우측 상단
- 레이블: `합·충·형·파`
- 토글: ON/OFF (OFF 상태가 기본)

### 사주표 셀 강조
관계에 해당하는 글자 셀에 색상 테두리를 입힘. 같은 관계끼리 같은 색.

| 관계 | 테두리 색 |
|------|----------|
| 합 (천간합/육합/삼합/방합) | 초록 (#2e7d32) |
| 충 | 빨강 (#c62828) |
| 형 | 주황 (#e65100) |
| 파 | 회색 (#757575) |

**우선순위:** 한 글자가 여러 관계에 해당하면 충 > 형 > 파 > 합 순으로 강한 것 표시.

### 요약 배지
표 바로 아래에 한 줄로 배지 나열. 해당 관계 없으면 숨김.  
배지 형식: `월간-일간 甲己합(토)` / `일지-월지 子午충` / `년지-월지-시지 寅午戌삼합(화국)`

## 계산 대상 관계

### 천간합 (5종)
甲己(토) / 乙庚(금) / 丙辛(수) / 丁壬(목) / 戊癸(화)

### 지지 육합 (6종)
子丑(토) / 寅亥(목) / 卯戌(화) / 辰酉(금) / 巳申(수) / 午未(토)

### 지지 삼합 (4종)
寅午戌(화국) / 申子辰(수국) / 亥卯未(목국) / 巳酉丑(금국)  
→ 4기둥 중 2개만 있어도 표시 (반합)

### 지지 방합 (4종)
寅卯辰(목) / 巳午未(화) / 申酉戌(금) / 亥子丑(수)  
→ 4기둥 중 2개 이상 있을 때 표시

### 지지충 (6종)
子午 / 丑未 / 寅申 / 卯酉 / 辰戌 / 巳亥

### 지지형 (5종)
寅巳申(삼형) / 丑戌未(삼형) / 子卯(이형) / 辰辰·午午·酉酉·亥亥(자형)

### 지지파 (6종)
子酉 / 丑辰 / 寅亥 / 卯午 / 巳申 / 未戌

## 구현 위치

- **계산 로직:** `static/js/display.js` 상단에 관계 데이터 상수 추가 + `computeRelations(pillars)` 함수
- **렌더링:** `renderSajuTable()` 수정 — 버튼 추가, ON 상태일 때 셀에 테두리 스타일 적용
- **요약 배지:** `renderSajuTable()` 반환 HTML에 배지 섹션 포함, 기본 hidden
- **토글 상태:** JS 변수 `sajuRelationMode` (boolean)
