## [완료] 사주 팔자 계산 v2 — datetime 기반 정밀도 개선

**목표:** 절기 교입 시각을 분 단위까지 반영한 정확한 사주 8글자 및 대운수 계산

**배경:** 기존 코드는 절기 날짜만 비교(date)하여, 절기 당일 출생 시 교입 시각 전후 구분이 안 됨.
대운수 오차 사례 확인: 1979-05-01 03:00 출생 → 청명이 4월 5일 밤 늦게 교입되어 날짜 기준 26일, 시각 기준 25일 차이 → 9 vs 8 (정답 8)

**변경 범위:**
- `data/solar_terms_time.json` 신규 — 1900~2100년 절기 교입 KST 시각 DB
- `saju/kr_timezone.py` 신규 — 한국 역사 표준시 보정 (DST, UTC+8:30)
- `saju/pillars.py` 재작성 — datetime 기반 년/월/일/시주 계산
- `saju/daeun.py` 수정 — datetime 기반 대운수 계산
- `saju/core.py` 수정 — date → datetime 변환 후 전달
- `app.py` 수정 — monthly-pillars 엔드포인트 함수명 변경
